# 明日方舟国服可读数据

当前基线：官方数据 **79.2.0**，资源 **26-11-06-12-42-25-70182449**，PC 客户端 **2.7.91**。

数据来自本地官方客户端的静态解包与结构核验。本仓库只保存可读数据、结构定义和报告所需图片；原始二进制、分析证据、工具源码、运行环境和生成的 HTML 不属于公开内容。历史从本次基线开始，旧混合仓库的版本标签没有导入。

| 路径 | 内容 |
| --- | --- |
| `gamedata/` | 完整可读 JSON、Lua、剧情文本；保留原始解包语义 |
| `schemas/` | 可分享的 FBS、结构及枚举定义 |
| `report-inputs/inputs.json` | 版本、报告输入映射和不含本机路径的来源摘要 |
| `report-inputs/tables/` | 仅在完整表与兼容投影不同或无法按哈希复用时保留的报告视图 |
| `report-inputs/skill_mechanics.json` | 匹配资源版本的技能、弹道、间隔与计时资料 |
| `images/` | 当前资源版本的图片索引与按 SHA-256 寻址的图片对象 |
| `version.json` | 官方、资源与客户端版本 |
| `manifest.json` | 数据契约版本、普通解包完整状态、报告就绪状态和所有受管文件的大小、SHA-256 |

兼容表优先引用 `gamedata/` 中哈希一致的原文件，另存的投影不覆盖完整表。完整报告需要十九张专题表、关卡、技能机制和同版本完整图片；普通解包完整不等于报告输入就绪。

使用数据前应核对 manifest 中的版本、就绪状态和逐文件哈希。manifest 不包含自身，哈希用于一致性校验，不代表官方数字签名认证。Lua 为静态解密文本，工具不会执行游戏脚本。资料展示与计算以游戏内实时结果为准。

本地 `reports/` 是报告输出，`工具/` 由独立工具仓库管理，均被本仓库忽略；没有 submodule，读取或下载本仓库不需要私有工具权限。报告生成工具单独管理，本仓库不提供其下载授权。

本轮仅建立本地基线，尚未配置或发布 GitHub 远程。
